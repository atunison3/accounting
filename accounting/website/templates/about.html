ABOUT THE PROJECT

Accounting software with a clear core.

The application separates domain rules, application services, and infrastructure so the accounting model stays independent from the web interface.

Built around accounting rules

Transactions use integer cents and must contain at least two lines with equal debit and credit totals. SQLite provides persistence, audit history, and soft deletion.

Designed to grow

The FastAPI interface exposes the application through both a browser-friendly dashboard and interactive OpenAPI documentation.
